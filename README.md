# Fantasy Brasileirão

Um aplicativo de fantasy football focado no Campeonato Brasileiro, inspirado no Cartola FC e no Sleeper.

## Visão Geral

- Crie seu time com jogadores reais do Brasileirão
- Pontue com base no desempenho real a cada rodada
- Dispute ligas privadas com amigos
- Gerencie seu orçamento no mercado de jogadores
